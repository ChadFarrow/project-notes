# boostmebitch

**Category:** Web/Apps
**Repo:** https://github.com/ChadFarrow/boostmebitch
**Deployed:** https://boostmebitch.vercel.app
**License:** MIT

## Description
V4V podcast/music player. Searches via Podcast Index, plays episodes, sends Lightning boosts with value-block splitting, publishes boost metadata as Nostr kind:1 notes (NIP-73 podcast tags), syncs favorites via NIP-51. Next.js 15 / React 19 on Vercel.

## PC2.0 Specs Used
- `<podcast:value>` - V4V splits
- `<podcast:valueRecipient>` - boost recipients
- `<podcast:guid>` - podcast identifier
- `<podcast:remoteItem>` - referenced episodes
- Boostagrams (TLV record over keysend)
