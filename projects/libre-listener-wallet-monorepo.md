# libre-listener-wallet-monorepo

**Category:** Lightning & wallets  
**Repo:** https://github.com/ChadFarrow/libre-listener-wallet-monorepo

## Description
Experimental non-custodial Bitcoin Lightning wallet (LDK WASM) for Podcasting 2.0 / Value-for-Value — exploring browser, PWA, WebLN-extension, and native-Android clients.

## PC2.0 Specs Used
- `<podcast:value>` - streaming sats / keysend
- `<podcast:valueRecipient>` - payment splits
